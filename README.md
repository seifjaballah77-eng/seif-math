# SEIF MATH AI

مختبر رياضيات عربي بواجهة متجاوبة للكمبيوتر والهاتف، يعمل كصفحة GitHub Pages ثابتة.

## الموجود في النسخة الأولية
- واجهة عربية RTL بتصميم داكن نيون مع وضع فاتح.
- محرك حساب عددي عبر Math.js للتعبيرات الرياضية.
- بحث عددي تقريبي عن جذور معادلات المتغير x ضمن المجال [-100, 100].
- حاسبات هندسية للأشكال الأساسية.
- رسم دوال ثنائية الأبعاد.
- بطاقات تأسيسية في عشرة مجالات رياضية.
- عشرة مسارات هندسية.
- أدوات تحويل أساسية وسجل محلي في المتصفح.

## التشغيل والنشر
1. افتح إعدادات المستودع على GitHub.
2. من **Settings → Pages** اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد اكتمال النشر سيكون العنوان عادةً: https://seifjaballah77-eng.github.io/seif-math/

## حدود مهمة
- لا يوجد اتصال بمساعد ذكاء اصطناعي سحابي في هذه النسخة؛ لا تضع مفتاح API سرياً داخل JavaScript أو ملفات GitHub العامة.
- الحلول العددية تقريبية وليست نظام جبر رمزي أو مدقق براهين.
- Math.js والخطوط تُحمّل من خدمات CDN، لذلك تحتاج بعض الوظائف إلى اتصال بالإنترنت.
- سجل العمليات محفوظ محلياً في المتصفح ولا تتم مزامنته بين الأجهزة.
